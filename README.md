# 🏧 ATM Machine – Python

A professional ATM machine simulation built using Python and Tkinter.

## 🚀 Features

- 🔐 PIN authentication
- 💰 Check balance
- 💵 Deposit money
- 💸 Withdraw money
- 📊 Daily withdrawal limit
- 💴 ATM cash denominations
- 🚫 Insufficient cash handling
- 📜 Transaction history
- 🧾 Mini statement / receipt
- 🔑 Change PIN
- 🚪 Logout and Exit
- 🖥️ Windows EXE application

## 🛠️ Technologies Used

- Python
- Tkinter
- PyInstaller

## ▶️ How to Run

Make sure Python is installed.

```bash
python ATM.py
